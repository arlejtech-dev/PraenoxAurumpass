# Praenox Aurum

Praenox Aurum is an Android biometric sound-synthesis application by Arlej Tech. It turns a
user's manually entered sleep and recovery data into a personalized soundscape while tracking
long-term patterns, context, recovery stability, and sleep debt.

## How it works

1. Enter daily HRV, resting heart rate, deep sleep, REM sleep, stress, and sleep duration.
2. Praenox calculates and saves the day's recovery state.
3. Select a sound palette and generate a biometric soundscape.
4. Listen in the built-in player and continue adding real daily data.
5. Pattern Drift, Learning, Milestones, Context, and Fusion develop from the saved history.

## Main features

- Personalized biometric soundscape generation
- Long-duration playback and WAV export
- Pattern Drift charts and saved-day comparisons
- Sleep Planner and sleep-debt tracking
- Optional lifestyle and sleep-context check-ins
- Learning reports, milestones, and progression
- Fusion recovery outlook with measured prediction performance
- Multiple local user profiles
- Full profile ZIP import/export and XLSX data export
- Per-user local backups

## Privacy

Praenox Aurum is designed as a local-first application. Health readings, profiles, context,
soundscapes, and learning history are stored on the user's device. Manual input avoids a required
dependency on cloud health services or delayed third-party synchronization.

Users should regularly export a complete profile ZIP and keep it in a safe location, especially
before changing phones, clearing application data, or uninstalling the app.
